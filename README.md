# UI Automation Testing Suite - Java & Selenium

This repository contains a lightweight UI automation testing framework built using Java. It validates critical user flows, including authentication and search capabilities.

## 🚀 Features & Architecture
- **BaseTest.java**: Sets up the test environment configuration, initializes the WebDriver instance, and handles clean teardown routines.
- **newLogin.java**: Automates end-to-end user authentication scenarios, including edge cases and field validations.
- **searchButton.java**: Validates search engine components, dynamic button behaviors, and results processing.

## 🛠️ Tech Stack
- **Language**: Java
- **Target Tooling**: Selenium WebDriver / TestNG
- **Design Pattern**: Page Object Model (POM) concepts for maintainable test cases.
